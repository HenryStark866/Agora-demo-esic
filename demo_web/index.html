Lo que corre aquí y lo que iría a producción

Motor simulado

Reglas explícitas y deterministas que reproducen el comportamiento del pipeline sin red: router por palabras clave, búsqueda híbrida BM25 + vector local, herramientas con datos ficticios y un verificador que exige que cada cifra aparezca en la evidencia.

Motor Claude (real)

Disponible cuando la página se abre con una sesión de claude.ai. El router, la generación con llamadas a herramientas y la verificación usan un modelo real con los mismos prompts del código. La recuperación y los datos en vivo siguen siendo locales y ficticios.

Cada llamada usa el plan de quien abre la página y pide su autorización la primera vez.

En producción

  • Azure AI Foundry: gpt-5.4-nano, gpt-5.4-mini y gpt-5.4 detrás de llm_gateway
  • Azure AI Search híbrido con filtro de audiencia, sensibilidad y vigencia
  • Document Intelligence, n8n auto-hospedado y Azure Functions
  • Content Safety y Prompt Shields

Código fuente

La carpeta codigo/ de la entrega contiene el orquestador, el validador, el flujo n8n de 20 nodos, el modelo de ROI y 42 pruebas. Para correr el demo: python demo.py.
